<p>Arent（アレント）は「建設業界の課題をテクノロジーの力で、共に解決していく。」を掲げ、「暗黙知を民主化する」をミッションとする会社です（東証グロース上場）。コンサルからシステム開発・事業化まで手がけるDX事業と、建設業のためのAIドッキングプラットフォーム「現場ドック（GENBA Dock）」、プラント配管の自動ルーティングを搭載した3D CAD「PlantStream」などのプロダクト事業を展開しています。現場ドックでは、AIがRevitを操作する「現場ドック BIM AI Agent」や、AIクラウド工程管理システム「現場ドック 工程管理（PROCOLLA）」などを提供しています。<br /><br />開発職のリモートワーク率は100%（2026年5月現在）で、地方からフルリモートで働くメンバーもいます。コアタイム付きフレックスタイム制を全社員に適用しており、副業も可能です。<br /><br />使用技術：C# / C++ / TypeScript / Go / Python / .NET / Unity / React / Laravel / AWS / Revit API / AutoCAD など<br /><a href="https://recruit.arent.co.jp/">採用サイト</a> / <a href="https://hrmos.co/pages/arentsaiyou/jobs">求人一覧</a> / <a href="https://note.com/arent3d/">note</a></p>
